# AI用語クエスト（RPG版）

本家「AI用語ドリル」と ABテストで比べるための、昔ながらのRPG風の別バージョン。出題内容は本家と同じ。

## 仕様
- 用語データは本家の `../terms.json` を共有する（コピーしない）。誤答の選択肢は同じ分野から選ぶ
- 4分野＝4エリア：ツールのそうげん（AIツール）→ きほんのもり（AIの基本）→ コードのどうくつ（操作・開発）→ ビジネスのしろ（仕事・導入）。前のエリアをクリアすると次が解放される
- 1問＝1ターン。エリアの全用語に1回ずつ正解するとクリア。不正解の問題は後でもう一度出る
- ふつうのモンスターは2回、ボスは4回の正解で倒せる。ボス戦だけ「用語→説明」、それ以外は「説明→用語」
- 不正解でHPが減り、0になるとエリアの最初からやり直し（経験値は残る）。「にげる」は途中経過を残してマップへ
- 経験値でレベルが上がり、最大HPと称号が変わる。進み具合は1問ごとに localStorage（aiYogoQuest.save.v1）へ保存
- 全エリアクリアでエンディング

## ルール
- rpg/ 内の index.html / style.css / app.js で完結させる（フレームワークなし）
- ドラクエなど既存作品のキャラクター・モンスター・音楽・ロゴ・名前は使わない。雰囲気だけ借りてすべてオリジナルにする
- 本家のキャラクター（ビット・フキダシ・トークン）は登場させない（ABテストでデザインの違いをはっきりさせるため）
- ゲーム画面なので常に暗い配色。スマホ対応
- 説明やコメントは日本語で
